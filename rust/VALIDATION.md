# Claude 网络守卫 2.1 历史验收记录

2026-10-16（America/New_York），Windows 11 x64。本节记录 Desktop 接入和静音可见告警；下方 2.0 内容保留为历史记录，不替代本轮验收。

## 2.1 自动化

完整构建通过 **52 项 Rust 测试与 15 项扩展测试**：20 项核心、16 项 Windows 集成、4 项协议/存储、10 项 Desktop 与进程识别、2 项告警状态测试。新增覆盖固定代理/PAC 冲突、设备策略遮蔽、内置 Code 环境冲突、旧进程需重启、首次启动拦截与已有会话保留、同一异常不重复提醒、恢复后再次提醒、卸载仅删除归属值。

## 2.1 实机结果

- 官方 MSIX Desktop 2.42304.0.0：完成当前用户固定代理接入；日志明确记录固定到 127.0.0.1:17890，观察到 8～9 条 Desktop 到守卫的实际 TCP 连接，不再直连 Clash 的 7897。
- 修复实际遇到的误报：打包启动环境把 HKCU 写入隔离副本，Desktop 在真实注册表中看不到该值。一次性当前用户任务启动守卫/安装助手，确保原生注册表视图；观察真实连接后才显示「已连接守卫」。安装、自启、配置数据目录继续沿用，临时任务在启动确认后删除。
- 强制结束守卫：9 条现有 Desktop 连接归零，17890 新建连接失败；Desktop 进程继续运行。恢复守卫后重新连接。
- 从已验证的 global 状态临时切换 rule：检测到阻断、现有 Desktop 连接全部关闭，原会话进程保留；专用 Desktop 入口返回拒绝。之后恢复测试前的 global 模式。
- 原入口测试使用 Windows AppsFolder 的 Claude 应用入口，观察到守卫的启动拦截日志与新 Desktop 进程全部退出；不是仅凭启动命令失败推断通过。测试明确获准重启空闲 Desktop，结束后恢复应用。
- 最终进程监测版本复测：模式变化约 980ms 检出，原入口启动约 1.21 秒后确认已关闭（含 500ms 确认等待）。这些是单次采样，不是零延迟承诺。UI Automation 可读到五个菜单操作名称。
- 截图检查：异常自动展开原因；收起后持续保留红色边框、红色状态点与「Claude · 连接受阻」。正常状态恢复为小黑胶囊。提示音开启，但没有更改系统静音或音量；未把静音时不可听的声音记为实听通过。
- 从打包终端运行安装器成功升级；从同一环境重新启动守卫仍使用原生注册表视图。桌面、CLI、安装包均为 Rust，扩展保持 JavaScript。

可复查脚本：`verify-desktop.ps1 -TestGuardExit`、`verify-desktop-blocking.ps1 -RestartDesktop`。后一项会临时切换模式并重启 Desktop，运行前必须确认没有进行中的 Desktop 任务；异常路径也恢复初始 global 模式。

空闲性能：Desktop 已运行、global/US、面板收起，采样约 10 秒。Working Set 84.2 MiB，Private Bytes 100.2 MiB，CPU 约为单核的 1.406%（32 逻辑核折算约 0.044%）。早期逐次扫描版本单核约 8.6～9.7%；改为保存已打开会话的进程句柄、快速检查退出后，再识别新启动，降低持续扫描开销。2.1 启动延迟未重新作三次基准；下方 2.0 启动时间不代表现在的一次性任务启动路径。

## 2.1 验证边界

- Desktop 正常页面路径、已建连接关闭、新启动拦截已执行；没有发送付费提示词，内置 Code/Cowork 的实际任务仍待单独验证。
- 固定代理不覆盖自动更新、外部浏览器、SSH 远端和不遵循代理的外部工具。启动监测需要守卫持续运行；守卫退出后网络仍因固定代理不可达而失败，但窗口启动不再受监测。
- 实际重启登录、物理跨屏/DPI、真实睡眠恢复、完整辅助功能体验继续标为待验证。没有把任务注册成功或手动调度等同于真实重启通过。
- 新增 Desktop 代理卸载的归属检查已在隔离测试注册表中通过；本轮未对当前机器执行完整卸载并重启 Desktop 的恢复验收。

## 体积与性能实测

安装包：旧 .NET 自包含包 291,842,220 字节（约 278.32 MiB）；Rust 包约 2.2 MiB。以交付目录中的文件大小和 SHA256SUMS.txt 为最终值。桌面和 CLI 的 DLL 依赖检查仅出现 Windows 系统组件。

方法：同一台 32 逻辑处理器电脑，3 次热启动；从创建进程到状态管道首次成功响应计时，随后空闲采样约 15 秒。此指标不是完成网络验证的时间。

| 平均响应，ms | 4816.6 | 174.0 |
| Working Set，MiB | 161.95 | 79.96 |
