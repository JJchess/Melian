Melian 2.3.0：Codex 额度与重置提醒。支持 Windows 11 x64 与 macOS 13+（Apple 芯片 / Intel）。

- 在同一小面板查看 Codex 剩余额度、正常重置时间和 Tibo 的明确重置预告。
- 自动复用本机 Codex 登录，不需要配置 X 密钥；公告由 codex-reset.com 聚合并提供原帖链接。
- 新预告或额度用尽后恢复时短暂展开，收起保留未读小点，静音时也能看到。
- 账号切换丢弃旧结果；查询失败和数据过期明确显示，不把公告当成账号实际恢复。
- 只读监测，不启动任务、不兑换额外重置次数、不读取聊天内容。现有安装命令可直接升级。

Windows 保留已验证的 Claude Desktop 与 Claude Code 接入。macOS 当前仅保护专用入口启动的 Claude Code；Desktop 接入尚未验证。两平台的自动网页保护继续停用，不修改浏览器或系统代理。

macOS 使用 ad-hoc 签名，尚未进行 Apple 公证。真实重启登录、多屏与睡眠恢复仍待实机验收。构建成功与自动化通过不等于这些场景已完成。
