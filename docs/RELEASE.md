Melian 2.3.1：修复 Tibo 重置预告漏报。支持 Windows 11 x64 与 macOS 13+（Apple 芯片 / Intel）。

- 修复每日系列中“reset day”“limit reset”等表述以及“Lands…”时间回复被漏掉的问题；支持连续回复中的更正与完成说明。
- 显示原帖发布时间和聚合源抓取时间；来源过期、暂无法更新与未发现预告分别表达。
- 历史记录接口失败不再隐藏新预告；分别遵守接口缓存和限流要求。
- 含糊的日期和时区保留原文，不生成不可靠的倒计时；社区确认和本人账号恢复继续区分。
- 保留 Codex 额度、正常重置时间和六秒提醒。公告仍由 codex-reset.com 聚合，可能延迟或遗漏，不是直接实时读取 X。现有安装命令可直接升级。

Windows 保留已验证的 Claude Desktop 与 Claude Code 接入。macOS 当前仅保护专用入口启动的 Claude Code；Desktop 接入尚未验证。两平台的自动网页保护继续停用，不修改浏览器或系统代理。

macOS 使用 ad-hoc 签名，尚未进行 Apple 公证。真实重启登录、多屏与睡眠恢复仍待实机验收。构建成功与自动化通过不等于这些场景已完成。
