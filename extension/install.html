CLAUDE GUARD浏览器接入指南

首次使用 · 约 2 分钟

连接你的浏览器

桌面应用检查 Clash 全局代理、所用节点和代理 IP 属地；扩展将 Claude 请求交给本机守卫。Chrome 与 Edge 需要分别安装，原有浏览器登录状态继续保留。

  1. 先运行 Claude 网络守卫安装程序，并启动桌面应用。
  2. Edge 打开 edge://extensions；Chrome 打开 chrome://extensions。
  3. 开启「开发人员模式」，选择「加载解压缩的扩展」，选择安装目录下的 extension 文件夹。默认目录为 %LOCALAPPDATA%\Programs\ClaudeGuard\extension；请以安装器实际位置为准。
  4. 将扩展固定到工具栏，打开扩展弹窗。确认没有代理冲突；Clash 运行于全局模式且代理 IP 属地确认为美国后，显示绿色「检查通过 · 已放行」。
  5. 完全退出并重新打开浏览器，以关闭安装前已经建立的连接。关闭全部窗口后，也需确认浏览器后台进程已退出。
  6. 在另一个浏览器重复以上步骤。多个浏览器用户配置也需要各自安装。

扩展 ID 应为 lgfobljoiaojjljlgpfhdaahppgdafkd。加载目录中的 manifest.json 必须保留原公钥；固定 ID 才能连接本机桥接程序。

连接如何受到保护

claude.ai、claude.com、anthropic.com 及其子域固定使用本机守卫，无直连后备。应用关闭、验证过期或网络状态不满足要求时，请求会失败。扩展后台休眠后，浏览器代理规则仍然保留。

其他网站跟随 Windows 当前的静态系统代理或直连设置。扩展每秒同步桌面程序提供的设置；不支持自动配置 PAC、自动检测或无法准确转换的绕过规则，遇到这些设置会阻断 Claude 并显示原因。扩展不解密 HTTPS，不读取页面内容或登录凭据。

常见问题

  • 本机桥接未连接：先启动桌面应用，再重开浏览器；仍失败可重新运行安装器修复 Native Messaging 注册。
  • 其他代理扩展接管：停用该浏览器配置中的代理扩展，再点击重新检查。企业策略锁定时需由管理员调整。
  • 桌面绿色，但网页失败：检查扩展弹窗，确认当前浏览器已接入；然后重试。网站或上游网络故障也会显示连接暂停页。
  • Clash 尚未启动：守卫会保持阻断。守卫开机自启不会替你启用 Clash 自启。

保护边界

扩展停用、卸载、未安装扩展的浏览器配置及其他浏览器不受本扩展保护。首版不支持无痕模式，禁止将无痕窗口作为受保护入口。状态检测有约 1～2 秒窗口，不能保证网络变化瞬间没有请求通过。其他域名和第三方登录站点不在浏览器域名保护清单中。

卸载

在两个浏览器的扩展管理页移除「Claude 网络守卫」，浏览器会恢复剩余有效代理设置；再从 Windows「已安装的应用」卸载桌面程序。桌面程序先卸载而扩展仍启用时，Claude 请求会继续失败，直到移除扩展。

本扩展无需上传数据，也不包含远程脚本。只与当前用户安装的本机桥接程序通信。
