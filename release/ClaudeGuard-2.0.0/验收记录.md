## 体积与性能实测

安装包：旧 .NET 自包含包 291,842,220 字节（约 278.32 MiB）；Rust 包约 2.2 MiB。以交付目录中的文件大小和 SHA256SUMS.txt 为最终值。桌面和 CLI 的 DLL 依赖检查仅出现 Windows 系统组件。

方法：同一台 32 逻辑处理器电脑，3 次热启动；从创建进程到状态管道首次成功响应计时，随后空闲采样约 15 秒。此指标不是完成网络验证的时间。

| 指标 | .NET 基线 | Rust 最终版本 |
|---|---:|---:|
| 三次启动，ms | 4519 / 4652 / 5278 | 181 / 177 / 163 |
| 平均响应，ms | 4816.6 | 174.0 |
| Working Set，MiB | 161.95 | 79.96 |
| Private Bytes，MiB | 95.10 | 104.73 |
| CPU，单核占比 | 11.01% | 0.31% |
| CPU，按 32 逻辑核折算 | 约 0.344% | 约 0.0097% |

限制：两次最终采样均为 global/已验证状态，但 .NET 基线在重启前、Rust 最终版本在重启后测量；缓存与显示环境可能不同。因此这些是实际运行采样，不能当作严格控制变量的性能结论；Private Bytes 并未下降。重启前 Rust 的较早测量不包含最终自启修复，未用于最终数值。
